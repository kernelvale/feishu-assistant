# 任务：修补式局部修改 —— 只改审核意见指出的位置

下面的正文已通过大部分验收，只有审核意见列出的具体问题需要修正。
你的任务不是重写，而是**最小修改**：只输出需要替换的片段，其余内容一个字都不许动。

只输出一个 JSON 对象，不要任何解释、前后缀或 markdown 围栏：

```json
{
  "edits": [
    {"find": "正文中需要修改的连续原文（从下方待修正正文里逐字摘录，不超过 80 字）",
     "replace": "改写后的文本（只改审核意见指出的问题，措辞风格与上下文一致）"}
  ]
}
```

规则：

- `find` 必须是待修正正文中**逐字存在**的连续片段，禁止改写、概括或编造原文没有的句子；
- 每条审核意见对应至少一条 edit；审核没有指出的位置一律不动；
- 修正事实问题必须以原文包为唯一依据；找不到依据就删除该论断，不得补充外部知识；
- 解读性概括要标明身份（"可以理解为""这提示"）；数字先交代口径与分母；
  示例必须能在原文包中找到直接依据；
- 确实没有可修改处时输出 {"edits": []}。
