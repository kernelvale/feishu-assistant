# 任务：骨架语义审核 —— 在正文动工前裁决教学规划

下面是一份论文精读的骨架（JSON 教学计划）。你的判决必须引用原文包中的证据；
空对空的"我觉得合理"一律视为不通过。只输出一个 JSON 对象，不要任何前后缀或围栏。

## 裁决清单（逐项核对）

1. **断链声明真实性（层数 ≥ 2 时）**：逐层核对 `break_if_merged`——把该层并入它
   指定的相邻层后，它声称失去的概念/推理环节是否真实存在于原文、且确实无法由
   相邻层覆盖。断点是编造的、相邻层本来就能讲的，判该声明不成立（该层应被合并）。
   **只有 1 层时**：改审该层是否承担论文不可缺少的核心主张——承担不了核心主张的
   "单层论文"属于规划错误。
2. **preparations 分配**：
   - 重复建立：同一前置概念被分配给多个建立章节；
   - 欠分配：存在"必须提前建立"（技术层无法自行引入）的概念，却没有任何章节负责；
   - 下放错误：技术层能自行引入的概念被下放进了 preparations。
3. **purpose/mode 举证分流**：
   - 可选功能（orientation/evidence/boundary 之外）理由不成立 → 删除该节或并入相邻节；
   - 必需功能（orientation/evidence/boundary）理由不成立 → 不删，重规划该节职责与标题；
   - `teaching_mode` 理由不成立 → 更换模式（层保留，不得借机删层）。
4. 唯一建立者制：同一概念只允许一个建立章节；后续章节与技术层回指它不算问题。

```json
{
  "pass": true,
  "issues": [
    {"kind": "断链|重复建立|欠分配|下放错误|purpose|mode",
     "location": "层名或节标题",
     "problem": "具体问题与原文证据",
     "action": "并入相邻层|删除节|并入相邻节|重规划节职责|更换模式|移除下放概念|补建概念"}
  ],
  "checks": [
    {"item": "断链|单层核心主张|preparations 分配|purpose/mode 举证",
     "result": "该检查为何成立的具体说明",
     "evidence": "原文包中支持该判断的依据"}
  ]
}
```

`pass: true` 时 `checks` 必须逐项列出且每项带来源依据；空 checks 或套话结果
将被程序拒收并按未通过处理。
